# Aspire Gems CMS-ready framework

Isolated multi-page luxury jewellery framework with working catalogue filters, sorting, product pages, bespoke page, and a centralized browser demo console at `admin.html`.

## CMS ownership
The `cms/` folder contains a Sanity Studio schema. Replace `REPLACE_WITH_FRIEND_OWNED_PROJECT_ID` only after the friend creates the Sanity project under their own account. No developer particulars are embedded.

## Current preview mode
`admin.html` stores edits in browser localStorage and exports JSON. It demonstrates the content model without accounts or costs. Shared authenticated editing becomes active when Sanity is connected.

## Editable content
Brand, contact details, headings, text, categories, filter labels/options, products, product attributes, media keys, section copy, SEO schema fields, images and video URLs.

## Isolation
This repository is standalone and has no dependency on PAIOS, POYA, or other projects.
